# PassOP - Local Password Manager 🔒

PassOP is a sleek, secure, and interactive password manager built with React and Tailwind CSS. This version focuses on privacy and simplicity by storing all your data locally in your browser's storage—no data ever leaves your device.

## ✨ Features

- **Local Storage:** Data is persisted in your browser's `localStorage`, ensuring privacy.
- **CRUD Operations:** Create, Read, Update, and Delete password entries easily.
- **Interactive UI:** Clean, modern interface designed with Tailwind CSS.
- **Copy to Clipboard:** One-click copy feature for passwords and usernames.
- **Toast Notifications:** Instant visual feedback for actions.
- **Responsive Design:** Works seamlessly on desktop and mobile devices.

## 🛠️ Tech Stack

- **React.js:** Frontend Framework
- **Tailwind CSS:** Utility-first CSS framework for styling
- **Vite:** Next Generation Frontend Tooling
- **React-Toastify:** For toast notifications
- **UUID:** For generating unique IDs

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation
1. Clone the repository:
  ```
git clone https://github.com/HarmanSing79/passwordManager1
```

2.Navigate to the project directory.
3.Install Dependencies:
```
npm install
```
4. Start the development server:
```
npm run dev
```

The app will launch at http://localhost:5173 (or the port shown in your terminal).
